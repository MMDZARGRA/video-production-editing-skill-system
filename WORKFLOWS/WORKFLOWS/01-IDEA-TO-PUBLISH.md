# Workflow: Idea to Publish

## 1. Intake and strategy
Define the objective, audience, one promise, CTA, format, constraints, and success metric in a brief. **Gate:** owner approves a decision-ready brief.

## 2. Research and concept
Collect verified facts, audience language, references, and competitor/context signals. Write one insight and 2–3 concept routes. Select the route that best serves the promise. **Gate:** facts are sourced; chosen angle is distinct and feasible.

## 3. Script, storyboard, and shot list
Write hook → value progression → proof/example → CTA. Translate every beat into picture, sound, text, and asset needs. Make a storyboard for complex sequences and a shot list with priority, location, talent, props, sound, and contingency coverage. **Gate:** production can proceed without improvising the story.

## 4. Production
Run a safety, rights, and technical check. Record room tone; slate/take notes; capture primary performance, cutaways, inserts, and safety takes. Check focus, exposure, framing, and monitored audio before moving on. **Gate:** coverage supports every scripted beat.

## 5. Media management
Copy from cards using verified transfer; keep two backups before formatting media. Apply `PROJECT_YYYYMMDD_CAMERA_CARD_TAKE` naming, create proxies if needed, log best takes, and preserve originals read-only. **Gate:** files relink and a restore test succeeds.

## 6. Editorial: assembly → rough → fine
Assembly proves all beats exist. Rough cut solves story, order, and pacing. Fine cut solves performance, rhythm, clarity, and edit points. Use temporary graphics/music only with rights tracked. **Gate:** approver signs off each story stage before finishing.

## 7. Finish: motion, sound, color
Build graphics from the approved message; mix dialogue first, then music and effects; correct shots before creating a look. Add captions and accessibility. **Gate:** no finish work obscures story or introduces unreadable/inaudible content.

## 8. Review, QC, master, versions
Collect consolidated timecoded notes; resolve P0 then P1 notes. Run technical/editorial QC. Export a high-quality master, then platform-specific versions with correct safe areas, captions, metadata, and thumbnails. **Gate:** manifest and approval are complete.

## 9. Publish, measure, learn
Publish to the planned schedule, verify playback and links, record baseline metrics, then review after enough data accumulates. Capture one lesson and one next test. **Gate:** project archive includes source, project file, master, versions, and learning note.
