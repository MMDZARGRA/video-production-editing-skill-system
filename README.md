# Video Production & Editing Skill System v1.0

A practical operating system for planning, making, finishing, publishing, and improving video. It is designed for a solo creator, editor, or small team and can be used in any Markdown app or Git repository.

## Start here

1. Read [the operating principles](00_SYSTEM/PRINCIPLES.md) and choose one project from `PROJECTS/`.
2. Create a project folder with [the project template](TEMPLATES/PROJECT-BRIEF.md).
3. Run [the end-to-end workflow](WORKFLOWS/01-IDEA-TO-PUBLISH.md) and its gates.
4. Use the skill matrix to select the smallest skill that removes the current bottleneck.
5. Log results with the review, assessment, and feedback templates; update your next experiment.

## System map

```text
Strategy → Research → Concept → Script → Storyboard → Shot List → Production
→ Media Management → Assembly → Rough Cut → Fine Cut → Motion → Sound → Color
→ Review/QC → Master → Platform Versions → Publish → Analytics → Feedback
```

The numbered folders are capabilities. `WORKFLOWS` describes sequence, `CHECKLISTS` protects quality, `TEMPLATES` turns decisions into reusable documents, and `REFERENCES` is a curated knowledge database.

## Skill levels

| Level | Evidence of ability |
|---|---|
| L1 Foundation | Can explain the concept and repeat a guided exercise. |
| L2 Competent | Can complete a standard task alone and resolve routine errors. |
| L3 Advanced | Can choose a method for a real brief, justify it, and optimize the result. |
| L4 Professional | Can diagnose quality issues, design a repeatable system, and teach or lead it. |

See [Skill Matrix](00_SYSTEM/SKILL-MATRIX.md), [dependencies](00_SYSTEM/DEPENDENCIES.md), and the [standard skill card](TEMPLATES/SKILL-CARD.md).

## How to maintain this repository

Treat v1.0 as a working handbook. Add examples to `PROJECTS/`, add lessons to `REFERENCES/RESOURCE-DATABASE.md`, and record material changes in [CHANGELOG](00_SYSTEM/CHANGELOG.md). A useful rule: do not promote a technique to a standard until it has worked in at least two projects.
