# Automation

**Purpose:** remove repeatable administrative friction while retaining human review for creative judgment, rights, factual accuracy, and release decisions.

**Good candidates:** folder creation, filename validation, proxy queues, transcription, caption drafts, review reminders, version manifests, asset inventories, and analytics collection.

**Procedure:** map the manual process; define input, output, owner, exception path, and validation; pilot on noncritical work; log failures; add a human acceptance gate. Quality means automation is reversible, observable, and saves time without hiding mistakes.
