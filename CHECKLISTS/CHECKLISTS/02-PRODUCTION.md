# Production Checklist

- [ ] Camera date/time, resolution, frame rate, shutter, white balance, exposure, focus, and media are checked.
- [ ] Dialogue is monitored on headphones; backup/room tone captured.
- [ ] Every essential line has a clean take and a safety take.
- [ ] Capture wide, medium, close, inserts, reactions, transitions, and location sound as needed.
- [ ] Record take notes, release status, and any technical problem before card handoff.
- [ ] Verify file transfer and two backups before formatting a card.
