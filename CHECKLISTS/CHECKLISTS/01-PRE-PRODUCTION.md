# Pre-production Checklist

- [ ] Brief, audience, promise, CTA, format, owner, deadline, and success metric are agreed.
- [ ] Facts, quotes, claims, licenses, releases, and brand restrictions are recorded.
- [ ] Script has a hook, progression, proof/example, and clear ending.
- [ ] Storyboard/shot list covers each scripted beat plus B-roll and contingency coverage.
- [ ] Location, permissions, schedule, call sheet, equipment, power, media, and backup plan are confirmed.
- [ ] Accessibility requirements: captioning, readable contrast, language, and audio description need are identified.
