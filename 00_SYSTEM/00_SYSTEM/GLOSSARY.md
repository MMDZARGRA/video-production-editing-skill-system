# Glossary

| Term | Meaning |
|---|---|
| Assembly | A fast, complete first arrangement of selected material in story order. |
| Beat | A meaningful unit of action, idea, or emotional change. |
| B-roll | Supporting footage used to add information, cover edits, or create rhythm. |
| CTA | The specific action requested from the viewer. |
| J-cut / L-cut | Audio starts before its picture / continues after its picture. |
| Log footage | Low-contrast capture designed for later color transformation. |
| Master | The approved highest-quality final deliverable from which versions are derived. |
| Proxy | A lightweight working copy linked to high-resolution media. |
| Rough cut | A coherent edit that proves story, pacing, and coverage before finishing. |
| Selects | Deliberately chosen clips, takes, and sound bites. |
| Version | A traceable variation of the same deliverable, named and logged. |
