# Skill Dependencies

Use these dependencies to decide what to learn next. A downstream skill can be practised early, but it becomes reliable only when its prerequisites are solid.

```text
Strategy → Research → Scriptwriting → Storytelling → Directing → Production
                         ↓                    ↓
Cinematography + Lighting + Audio ───────────┤
Media Management → Editing → Motion / VFX / Sound / Color → Review & Delivery
Graphic Design + Typography ──────────────────┘
Distribution → Analytics → Strategy
AI and Automation support every stage; they do not replace editorial accountability.
```

| If the failure is… | Strengthen first |
|---|---|
| Low retention in the first seconds | Strategy, research, concept, script hook |
| Video feels slow or confusing | Storytelling, editing, sound |
| Footage looks amateur | Cinematography, lighting, production design |
| Viewer cannot hear or trust it | Audio, research, review/QC |
| Branded graphics feel inconsistent | Graphic design, typography, motion |
| Revisions are chaotic | Brief, media management, review workflow |
| Effort does not create results | Distribution, analytics, strategy |
