# Assessment and Learning Loop

## Score a skill demonstration

Score each dimension 1–4. A level is earned only when evidence is repeatable on two different briefs.

| Dimension | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Intent | Cannot state purpose | States a generic purpose | Connects choices to audience outcome | Anticipates trade-offs and sets criteria |
| Execution | Requires step-by-step help | Completes routine task | Adapts to real constraints | Produces robust, reusable practice |
| Judgment | Copies an example | Makes a plausible choice | Explains alternatives and consequences | Diagnoses others’ work and improves system |
| Quality | Errors block use | Meets minimum technical standard | Delivers polished, consistent result | Raises the standard for a team |

## 30-minute post-project loop

1. Save final metrics and the final video link.
2. Write: *what worked, what surprised us, what failed, what we will test next*.
3. Score the weakest stage in the workflow.
4. Turn one lesson into a checklist, template improvement, or practice drill.
5. Schedule the next experiment with one changed variable only.
