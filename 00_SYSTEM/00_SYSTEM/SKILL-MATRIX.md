# Skill Matrix

| Domain | L1 Foundation | L2 Competent | L3 Advanced | L4 Professional |
|---|---|---|---|---|
| Strategy | Name objective and audience | Write a focused brief | Select a defensible content angle | Build a content system from business goals |
| Research | Find credible sources | Verify claims and organize notes | Synthesize tensions and insight | Create reliable research standards |
| Scriptwriting | Write a hook and CTA | Draft a clear script | Write for voice, visual, and retention | Build repeatable formats and edit scripts |
| Storytelling | Identify setup/change/payoff | Structure a short narrative | Control beats and emotion | Diagnose story failure and direct rewrites |
| Directing | Communicate a shot intention | Run a simple shoot | Direct performance and coverage | Lead a set with a clear creative language |
| Cinematography | Exposure, focus, framing | Capture consistent usable coverage | Design visual language | Plan and lead cinematography choices |
| Lighting | Place a key light safely | Shape a repeatable interview setup | Design mood and continuity | Solve mixed, changing, or constrained locations |
| Audio | Record clean dialogue | Monitor and repair routine issues | Design a sound plan | Set standards for production and post sound |
| Editing | Cut, trim, organize | Build a coherent rough cut | Control pace and meaning | Diagnose and standardize editorial systems |
| Motion design | Animate basic properties | Build readable title systems | Design motion language | Create reusable motion packages |
| VFX | Use masks and tracking | Execute clean common composites | Plan invisible effects | Supervise effect-heavy post workflows |
| Color | Correct exposure and white balance | Match shots and export correctly | Create a controlled look | Build color pipeline and QC standards |
| Graphic design | Use hierarchy and contrast | Build consistent layouts | Design systems for multiple formats | Own a visual identity across campaigns |
| Typography | Set readable type | Apply a type scale | Make kinetic type serve pacing | Define and govern a type system |
| AI | Use approved assistive tools | Verify outputs and disclosures | Design human-in-the-loop workflows | Set policy, evaluation, and provenance rules |
| Media management | Ingest and back up | Relink, proxy, archive | Design project storage | Operate team-wide data safety workflow |
| Review/QC | Spot common errors | Run a checklist | Prioritize notes by impact | Build acceptance criteria and review culture |
| Delivery | Export one valid file | Deliver a version package | Handle specifications and masters | Standardize multi-platform delivery |
| Distribution | Publish with metadata | Select format and package | Plan campaign sequencing | Own channel strategy and experimentation |
| Analytics | Read core metrics | Form one evidence-based insight | Run controlled content experiments | Build learning dashboards and strategy loop |
| Automation | Automate a repeatable task | Validate automation outputs | Design resilient integrations | Govern automation systems safely |

Assessment evidence and scoring are in [ASSESSMENT.md](ASSESSMENT.md).
