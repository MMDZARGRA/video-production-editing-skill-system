# Media Management

**Purpose:** make every asset findable, linked, backed up, and recoverable. A fast edit begins with reliable data, not a clever timeline.

**Standard structure:** `01_ADMIN`, `02_MEDIA/ORIGINALS`, `03_AUDIO`, `04_PROJECT_FILES`, `05_GFX`, `06_EXPORTS`, `07_REVIEW`, `08_ARCHIVE`. Name files `PROJECT_YYYYMMDD_DESCRIPTION_v01.ext`; never use `final-final`.

**Practice:** ingest a simulated card, create two verified backups, generate proxies, relink a moved project, and document restore steps. Quality means another editor can open the project and locate any source without guessing.
