# Lighting

**Purpose:** make subjects readable, dimensional, and emotionally appropriate while preserving continuity. Start with the available light, then shape and control it.

**Procedure:** set exposure for the subject; choose key direction and softness; manage fill, background separation, practicals, spill, and mixed color temperatures; document the setup.

**Practice:** light one interview in neutral, dramatic, and warm commercial styles using the same location. Quality means eyes, skin, and background support the intended tone with no distracting inconsistency.
