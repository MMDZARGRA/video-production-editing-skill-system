# Resource Categories and Buying Rules

## Core library

- **Official documentation:** editing software, camera, audio, color management, platform specifications. Use for current procedures and technical settings.
- **Primary practice references:** finished films, campaigns, creators’ own work, and behind-the-scenes material. Use for beat maps and visual analysis.
- **Expert explanation:** working professionals with concrete examples. Use to generate a drill, then test rather than copy blindly.
- **Rights and accessibility references:** platform terms, licensing agreements, caption/accessibility standards, and local law where applicable. Use to define release constraints.

## Before adding a paid course, plugin, or tool

State the bottleneck, measurable outcome, cost, alternatives, and a two-week practice plan. Do not buy a tool to avoid learning the decision it is supposed to support.
