# Golden Rules by Stage

| Stage | Rule |
|---|---|
| Strategy | One video should make one primary promise to one primary audience. |
| Research | A compelling claim that cannot be sourced is a risk, not an asset. |
| Script | If a line only repeats the picture, cut it or make the picture do more. |
| Production | Verify monitored dialogue and backup media before moving on. |
| Editing | Solve meaning before rhythm; solve rhythm before decoration. |
| Motion/type | If it cannot be read at normal speed on a phone, it is not finished. |
| Sound | Dialogue owns the mix unless a deliberate story reason says otherwise. |
| Color | Match before look; correct before stylize. |
| QC | Inspect the exported file, not only the timeline. |
| Analytics | Do not change five things after one result; test one meaningful variable. |
