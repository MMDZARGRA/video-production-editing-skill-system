# Typography

**Purpose:** make language readable, expressive, and consistently ranked. In video, type must be understood at speed and at small size.

**Procedure:** choose approved families; define size/weight/line-length scale; control alignment, contrast, line breaks, tracking, and duration; test captions on device.

**Practice:** set the same 30-word message for title, lower third, caption, and data point. Quality means no orphaned meaning, unsafe crop, unreadable contrast, or animation that interrupts reading.
