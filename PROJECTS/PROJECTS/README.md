# Project Portfolio and Practice

Use one folder per project: `YYYY-MM-DD_project-slug/`. Start every project from the brief and end with the analytics review. Keep only lightweight documentation and project files here; store large media outside Git or in approved asset storage.

## Recommended practice ladder

1. **15-second hook remake:** recreate the structure of a strong opening with original footage; assess clarity and pace.
2. **60-second explainers:** one audience, one problem, one promise, one proof, one CTA.
3. **Interview story:** plan coverage, record clean dialogue, and edit a 90-second change arc.
4. **Product/social campaign:** create master plus three platform adaptations without losing the promise.
5. **Client-style project:** work through brief, approval gates, consolidated feedback, delivery manifest, and analytics review.
